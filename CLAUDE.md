## Boundaries and Permissions

### You ARE allowed to read and edit:
- Backend/server.js
- Frontend/index.html
- Frontend/script.js
- Frontend/style.css

### You are NOT allowed to touch:
- .env (never read, modify, or print its contents)
- .gitignore
- package.json
- package-lock.json
- node_modules/
- Any file outside the RecipePlanner folder

### You are NOT allowed to:
- Install any new npm packages without asking first
- Create any new files without asking first
- Delete any existing files
- Hardcode the API key anywhere
- Make any Spoonacular calls from the frontend directly
